# Transcripts

Verbatim source transcripts for videos in the Codex source catalog (section 16 of
`../max-rogers-fitness-knowledge-codex.md`).

## Rules

1. **Files here are verbatim.** Do not clean up timestamps, filler words, or transcription
   errors. These are the evidence of record — if a doctrine claim is challenged, this file is
   what settles it.
2. **Metadata does not live in the transcript.** It goes in that video's source-catalog entry.
   The `transcript_path` field of the video record points here.
3. **Filename is the title slug**, lowercase and hyphenated, `.txt`.
4. **A transcript on file upgrades a video's evidence depth to `DIRECT`** for claims actually
   spoken in it — and only those. It does not license restating the channel's other videos as
   direct quotes.
5. If the source URL is not known at ingestion time, record it as unresolved in the catalog
   entry rather than inferring one from a similar title.
